# wifi-stubs

Заглушки для MTK-only подсистем, которых в mainline нет, и для объектов,
которые сознательно выключены из сборки (STP-over-UART, SDIO-транспорт,
WMT factory-step).

Правила (docs/wifi-port-log.md, майлстоун 2):

- каждая заглушка обязана **печатать предупреждение** при первом вызове, чтобы
  отказ на железе не приписывался не тому месту;
- в шапке файла — `SPDX-License-Identifier: GPL-2.0`, происхождение и `TODO`;
- заглушка возвращает «не поддерживается» (`-ENOSYS`/`NULL`/0, как ждёт
  вызывающий), но не падает.

Файлы подключаются к сборке через `scripts/remote/wifi-kbuild/*.Kbuild`
(`wmt_drv-y += ../stubs/<file>.o`), то есть попадают в тот же модуль.
